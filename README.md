# Controlling part for a marin airconditioning system like MACS 7000

Based on Arduino


# function

    * includes 
    * timer 
    * 4 Temperatur sensors
    * pcc for fan motor (235V)
    * relais switch for compressor
    * solid state relais for cooling water pum
    * 12V switch for cooler fans (5 * 1.5W fan)




# requirements

get analogKbd and phaseCutCtrl and put it in the library directory of Arduino IDE

git clone https://github.com/benoitjoh/analogKbd 
git clone https://github.com/benoitjoh/phaseCutCtrl
